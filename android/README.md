# 此刻 Android 试装版

当前输出：`outputs/cike-0.1.4-debug.apk`。包名 `com.cike.moment`，版本 `0.1.4`，最低 Android 8.0（API 26）。

## 已接入

- 离线网页资源封装，不申请网络或存储权限。
- 本机记录、常用标签及自定义词持久保存；不启用系统云备份。
- 同一日历内点击查看、长按进入日期范围选择、跨月选择，以及 7 / 14 / 30 天快捷选择。
- 所选日期导出为可编辑 Word：黑白横线表格、出现天数、五格方块与实际程度均分；未评分不计零，后附逐日原文。通过系统文件保存器选择目标位置。
- Android 返回键依次关闭弹窗、退出日期选择、返回记录页；旋转屏幕保留当前页面。

## 构建

工具保存在项目 `.build-tools`（已加入 Git 忽略），不会修改全局 Java 或 SDK 配置。
使用 Microsoft OpenJDK 21、Google SDK Platform 35 和 Build Tools 35.0.0。构建脚本直接调用 aapt2、javac、D8、zipalign 和 apksigner，无需 Gradle 下载完成。

执行 `powershell -NoProfile -ExecutionPolicy Bypass -File android/build-apk.ps1`。
Windows 沙箱中 aapt2 可能崩溃，需在经授权的普通进程中运行。若中文路径导致工具失败，可临时 `subst R: "项目绝对路径"`，再从 `R:\android\build-apk.ps1` 执行，完成后 `subst R: /D`。

试装签名密钥保存在 `.build-tools/cike-debug.jks`，应保留以便后续覆盖升级。当前为开发签名，尚未配置正式发布签名。
